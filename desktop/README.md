# 视频发布台

独立的 Tauri 桌面工作台。目前只适配抖音：桌面端整理视频、标题、简介、标签、横竖封面和内容声明；浏览器扩展在用户默认的 Chrome 或 Edge 中打开抖音创作者发布页、上传并填写资料。**软件和扩展不会点击发布按钮。**用户在抖音页面检查后亲自发布，再回到桌面端确认记录。

项目主页：[ytton/video-poster](https://github.com/ytton/video-poster)。

## 安装扩展

1. 启动桌面程序，进入“浏览器扩展”页，复制扩展目录。
2. 在默认 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。
3. 开启开发者模式，选择“加载已解压的扩展程序”，选中刚复制的目录。
4. 在该浏览器自行登录抖音创作者中心。登录状态只由浏览器管理，桌面程序不会读取或保存 Cookie。

扩展目录由桌面程序写入应用数据目录。更新软件后在扩展管理页点击“重新加载”即可读取新版本。暂不支持 Firefox 或其他不兼容 Chromium Manifest V3 的默认浏览器。

## 使用

在“发布”页选择视频并填写资料，点击“去抖音填写”。系统默认浏览器会打开本机连接页，扩展接收本次任务并转到抖音上传页。视频和封面经仅监听 `127.0.0.1` 的临时桥接服务传给扩展；服务使用每次启动随机生成的令牌，软件退出后不可访问。扩展会在抖音页面显示进度和失败原因，可在页面中重试。

填表完成后任务显示“待人工发布”，不算发布成功。用户在抖音点击发布并在后台确认作品出现后，可在任务页点“确认已发布”。作品管理按视频 SHA-256 归档；此前版本的本机记录继续保留。旧 CLI 的 Cookie 不会导入默认浏览器。

抖音页面经常变更，封面和声明控件可能需要调整；扩展找不到控件时会停下并提示用户在抖音页面手动完成。上传中的浏览器标签由用户控制。停止任务会断开本机文件接口，已交给抖音的上传需在页面中手动停止。较大的视频会由浏览器扩展读入内存后交给网页上传，可能受到浏览器内存限制。

## 开发与打包

需要 Node.js、pnpm、Rust 和 Windows WebView2。桌面程序不需要 Python 或 `social-auto-upload` CLI。

```powershell
cd desktop
pnpm install
pnpm tauri dev
pnpm tauri build
```

`pnpm build` 检查 TypeScript 并构建前端。Windows 安装包位于 `src-tauri/target/release/bundle/nsis/`。扩展源码位于 `extension/`，随桌面二进制打包。
