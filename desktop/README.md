# 视频发布台

独立的 Tauri 桌面工作台。目前适配抖音：软件管理本机作品，Chrome / Edge 扩展在用户自己的浏览器中补齐发布表单。用户最后在平台页面亲自点击发布。项目主页：[ytton/video-poster](https://github.com/ytton/video-poster)。

## 开发版扩展

扩展源码位于 [`desktop/extension`](extension/)。在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，选中该目录。修改扩展代码后，在扩展管理页点击“重新加载”。桌面程序的“浏览器扩展”页也会显示当前开发目录。

安装后，在桌面程序“浏览器扩展”页点击一次“连接扩展”。浏览器连接页会显示结果。扩展只保存本机桥接地址和连接令牌，不读取或保存抖音 Cookie、密码；登录完全由用户自己的浏览器管理。若软件换了端口或连接失效，重新点击“连接扩展”。目前仅支持兼容 Chromium Manifest V3 的 Chrome / Edge。

## 作品流程

1. 首页为作品管理，按视频文件 SHA-256 归档，以 3:4 封面卡片展示。点击卡片进入编辑页；右上角锁定按钮把作品设为扩展当前发布项目。作品管理不展开详情。点击“新建作品”进入编辑页，选择视频并填写标题、简介、标签、横竖封面和声明。
2. 左侧“平台”页可勾选发布目标并打开各平台页面；选择会随作品保存，锁定作品后修改勾选也会更新该作品。只有抖音支持扩展自动填写，其余平台由用户在浏览器中自行填写发布。编辑页显示所选平台和已经确认发布的平台。点击“发布”后保存作品资料，抖音生成待填写任务并切回现有抖音创作者标签；没有现有标签时打开上传页。其他已选平台会打开对应页面，发布后需在编辑页手动确认成功。再次点击作品卡片可修改资料，重新发布会生成新的抖音任务快照。
3. 在抖音创作者页面点击扩展图标。弹窗列出待填写作品，当前发布任务会高亮。首次点击“自动填写”后，扩展先检查当前页面；已有标题、简介、标签、封面会保留。填写失败后点击页面上的“补齐剩余内容”，或在扩展弹窗选择同一作品继续，扩展只检查现有表单并补缺项，不刷新页面或重新上传视频。若当前页面没有可识别的上传表单，扩展会停下并提示核对；手动打开上传页会使用新标签。
4. 扩展会尝试填写封面及作品声明；若页面控件变化，会显示具体失败项，用户可直接在抖音页面完成。任务显示“待人工发布”时，仍需用户核对并点击平台发布按钮。看到作品出现在抖音后台后，再到软件任务页点“确认已发布”。

浏览器中的视频和封面通过仅监听 `127.0.0.1` 的本机桥接服务传给扩展。软件退出后服务不可访问；扩展不保留媒体文件。较大视频会由浏览器读入内存，可能受到浏览器内存限制。关闭浏览器标签不会自动终止抖音已开始的上传。此前版本的本机作品与任务记录继续保留，旧 CLI Cookie 不会导入浏览器。

## 开发与打包

需要 Node.js、pnpm、Rust 和 Windows WebView2，不需要 Python 或 `social-auto-upload` CLI。

```powershell
cd desktop
pnpm install
pnpm tauri dev
pnpm tauri build
```

`pnpm build` 检查 TypeScript 并构建前端。Windows 安装包位于 `src-tauri/target/release/bundle/nsis/`。打包版会把扩展写入应用数据目录，扩展管理页需在软件更新后点击“重新加载”。
