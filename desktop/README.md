# 视频发布台

独立的 Tauri 桌面工作台。抖音、百家号和大鱼号通过 Chrome / Edge 扩展在用户自己的浏览器中补齐发布表单。用户最后在平台页面亲自点击发布。项目主页：[ytton/video-poster](https://github.com/ytton/video-poster)。

## 开发版扩展

扩展源码位于 [`desktop/extension`](extension/)。在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，选中该目录。修改扩展代码后，在扩展管理页点击“重新加载”。桌面程序的“浏览器扩展”页也会显示当前开发目录。

安装后，在桌面程序“浏览器扩展”页点击一次“连接扩展”。浏览器连接页会显示结果。扩展只保存本机桥接地址和连接令牌，不读取或保存平台 Cookie、密码；登录完全由用户自己的浏览器管理。若软件换了端口或连接失效，重新点击“连接扩展”。目前仅支持兼容 Chromium Manifest V3 的 Chrome / Edge。

## 作品流程

1. 首页为作品管理，按视频文件 SHA-256 归档，以 3:4 封面卡片展示。点击卡片进入编辑页；右上角锁定按钮把作品设为扩展当前发布项目。作品管理不展开详情。点击“新建作品”进入编辑页，选择视频并填写标题、简介、标签、横竖封面和声明。
2. 左侧“平台”页可勾选发布目标；选择会随作品保存。编辑页点“保存作品”仍停留在当前页。每个平台独立显示“去发布”，点击后该平台进入进行中，浏览器优先切回已有上传页；首次没有上传页时才打开新页。其他平台不自动连开。已开始的平台可点“继续发布”，不会重新建立任务或强制重新上传。
3. 在抖音、百家号或大鱼号的发布页点击扩展图标，选择当前平台作品自动填写。扩展会先读取发布前作品记录作为检验基线，再检查当前表单并补缺项；已有视频不会重新上传。百家号的简介、标签及部分声明，大鱼号的分类和转载原文链接仍需在网页核对或补填。页面结构变化时扩展会提示失败项，最终发布按钮始终由用户亲自点击。
4. 平台发布完成后回到同一编辑页，点击对应平台的“检验已发布”。扩展只读查询或检查后台作品记录，须找到标题匹配、状态为已提交或已发布且不在发布前基线中的唯一作品，才写入本机已发布记录。未找到、同名歧义或页面结构变化时保持待检验，继续在平台后台核对后重试。尚未自动适配的平台可打开后台，但在接入记录检验前不会计为已发布。

浏览器中的视频和封面通过仅监听 `127.0.0.1` 的本机桥接服务传给扩展。软件退出后服务不可访问；扩展不保留媒体文件。较大视频会由浏览器读入内存，可能受到浏览器内存限制。关闭浏览器标签不会自动终止平台已开始的上传。此前版本的本机作品与任务记录继续保留，旧 CLI Cookie 不会导入浏览器。发布前记录基线保存在扩展的会话存储中；浏览器会话清除后，已有任务的自动检验会提示基线缺失，不会猜测成功。

## 开发与打包

需要 Node.js、pnpm、Rust 和 Windows WebView2，不需要 Python 或 `social-auto-upload` CLI。

```powershell
cd desktop
pnpm install
pnpm tauri dev
pnpm tauri build
```

`pnpm build` 检查 TypeScript 并构建前端。Windows 安装包位于 `src-tauri/target/release/bundle/nsis/`。打包版会把扩展写入应用数据目录，扩展管理页需在软件更新后点击“重新加载”。
